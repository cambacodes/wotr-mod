## Decisions and guards

Positive initial evidence requires the exact loaded Drezen area, source scene, native spawner identity, saved actor reference, blueprint, registry entry and reciprocal storage.
The extra observer checks reject historical death despite current life and marked destruction that the delegated generic inspector treats as unresolved.
Competing saved spawners cannot grant an arbitrary first-match success.
Hidden living storage is allowed deliberately because this is correspondence eligibility, not a claim that the actor can currently be addressed in a visible scene.
The source neither duplicates nor unhides that actor.

Saved-area negative inspection is separate and never returns Available.
It enumerates the existing SavedAreaStates plus loaded area, deduplicates the same area object, and treats separate matching area representations as a conflict.
Exact AreaGuid and scene name constrain the search.
It does not call a native get-or-create state method.
For unloaded storage, a missing global registry entry is permitted while an affirmative collision remains incompatible.
A null holding state during reconstruction is tolerated, while a nonnull contradictory holding state is rejected.
These distinctions avoid making ordinary unloading revoke a previously earned letter exchange.

Known saved death is read before requiring a retained actor.
Thus HasDied still invalidates when the actor itself has disappeared, and retained actor death still invalidates with an empty off-area registry.
The independently rerun cases cover both paths, destruction, duplicate storage, registry disagreement and missing unresolved history.
This repairs the earlier loaded-only negative result described in the author's report.

Unknown or incompletely readable native state returns neither Available nor Invalidated.
The broad exception handling does not turn an unreadable object into positive initial evidence.
It also cannot preserve evidence that native state no longer contains; this service deliberately writes no permanent death marker.
That limit is accurately disclosed rather than represented as universal recovery support.

Main reads authored and native history before invoking the observer.
It treats an existing noncompleted office fact as active even if ordinary Playing presence is temporarily suspended.
The extra explicit present check preserves the positive native guard.
Only a story declaring the new acquisition flag enables this optional observer integration.
Available is ephemeral snapshot evidence, and Invalidated is published only for a player who actually sent the new letter or earned its private access.
Old histories without either authored flag are not silently migrated.

Rules classifies both observation flags as native-derived, so an incompatible remote conversation stops during continuation as well as at entry.
Validation rejects attempts to write either through a story choice or collide with native binding maps.
The known-condition scan recognizes them without creating persistent authored flags.
The authored candidate's negative continuation witness previously failed before this classification and passes with the inspected wiring.
