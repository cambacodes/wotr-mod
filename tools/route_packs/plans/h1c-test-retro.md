**Candidate:** use one pinned gate kind/selection from the job record, surfaced before execution. Plan jobs check scope/document/encoding; writing jobs run the small set in §T; merges run generation/compatibility/managed construction; milestones own exhaustive campaigns. Reuse E7's selectors and H4's existing record/command authority instead of adding a second scheduler. An unrecognized shared edit must choose an explicit conservative shared set, not silently get an empty selection or expand to unbounded FULL. H4 already tests empty/`all` suite arguments, renamed compiled runners, descendants, timeout/cancellation and expired grants; preserve those controls.

**Owner/completion:** coordinator + harness owner. Host testguard rejection is an incomplete gate, never a pass; do not bypass it with a renamed job or scratch path.
