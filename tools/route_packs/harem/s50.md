The private notice distinguishes `cost.egg_withheld` from `debt_claimed` and
unnamed responsibility using separate guarded nodes, never conditional dialogue
paragraphs. All three original saved-egg sources retain `egg_owed`. The ready
adapter requires both that witness and `hatched`. Both body variants read current

Only remedy answers require the existing `cost.claim_given_up`. No free route
renunciation, no diet overwrite, no hunger punishment, no harem/page gate for
the protected private errand. No current Devarra reply is added: her existing
solo callback remains responsible for its flight, return and current-loss gates.

The check decides whether the cart reaches the kiln intact. The paid terminals
use the existing GLOBAL-TC full-debit transaction, 100/150 Materials. Their text
offers the delivery before payment; published witnesses and Ledger report its
inspection. Failure/refusal keep Nidalynn's own food available. One recovery
may resolve support, never fixed antagonism. The Ledger, Nidalynn's two living
solo epilogue pages, her Last Call page and the Commander's Last Word read the
delivery and her own food/night costs. These are payload registrations only;
shared source files stay untouched.

Integration dependencies requiring shared-code ownership:

- The coordinator's discovery call is absent. `story.py.make_story()` returns
  `dict(Scenes=scenes, Etudes=refs)` directly, with no `payload` local. Registration
  must run after the expansion's routes, current attendance adapters, Ledger and
  household have been assembled. This job does not edit the forbidden factories.
- `src/Story.cs` `ParticipantsAvailable` and its Python simulation require
  `nidalynn.harem.eligible` for every declared participant. Thus the required
  private no-romance errand currently fails availability despite valid earned
  presence. ER-H2 requires the declared participant; removing it or granting
  romance here would violate the contract. Tests expose this shared blocker.
- Dedicated post-payment delivery narration with atomic completion/allowance
  needs the shared transaction consequence interface; this row records inspected
  delivery in the paid terminal and Ledger without a second completion.
- The shared delay calculation uses the newest timestamp among all required
  flags. A later `form_chosen` therefore restarts custody/recovery's interval,
  although the sheet requires the original predecessor clock across body changes.
  ER-H2 requires the exact body gate, so this cannot be fixed by omitting it or
  substituting a row-owned alias. The shared clock needs coordinator correction.

This is reviewable row content, not a claim of deployed or full runtime behavior.
